System Monitor 2.1

Программа для мониторинга состояния компьютера Windows. Следите за системными ресурсами и показателями производительности в одном окне.

↓ СКАЧАТЬ ДЛЯ WINDOWS

Версия 2.1 · Windows 10 · NELVARIS Technologies

Возможности

  • Мониторинг загрузки процессора (CPU)
  • Использование оперативной памяти (RAM)
  • Информация о диске C:
  • Отображение информации о GPU
  • Скорость сетевого соединения
  • Графики истории CPU и RAM
  • Автоматическое обновление показателей

Системные требования

ОС

Windows 10 или новее

Тип

Приложение для Windows

Версия

2.1

Загрузка

Загружайте программу только с официальной страницы NELVARIS Technologies. Перед запуском Windows может показывать предупреждение о неизвестном издателе, поскольку приложение не имеет цифровой подписи.
